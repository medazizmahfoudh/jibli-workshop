# Welcome

This repository follows the Jibli workshop slides. Jibli is a food delivery app. Dhia opens it, picks a Plat Healthy (12.5 TND) at Mamma Chemi, and pays. By the end of the day you will have written the backend that makes that possible.

## How a step works

1. Switch to the exercise branch: `git switch step-01-jvm/exercise`.
2. Read `EXERCISE.md` (this file gets replaced on every step).
3. Write the code. Look for `TODO(step-NN)` comments.
4. Run the check from the "Check yourself" section until it is green.
5. Stuck? `git switch step-01-jvm/solution` shows the answer.

## Before you start

Check your tools:

```bash
java -version      # 21 or newer
git --version
./mvnw -v          # downloads Maven the first time, needs the network
```

Then go to the first exercise: `git switch step-01-jvm/exercise`.
